# 환경공무관 인성검사 연습

은평구 환경공무관 채용 인성검사 대비용 연습 웹페이지입니다.
500문항(250쌍) 중 200문항을 무작위로 뽑아 풀고, 끝나면 채점과 피드백을 보여줍니다.

> 연습용 채점입니다. 실제 검사 기관의 판정 기준과 다릅니다. 응답 습관 점검용으로만 쓰세요.

## 채점 항목

| 항목 | 보는 것 | 안정 기준 |
|---|---|---|
| 일관성 | 같은 성향을 다르게 물은 짝 문항의 답이 맞는지 | 85% 이상 |
| 허구성 | "한 번도 ~한 적 없다" 같은 문항을 과장했는지 | 45점 이하 |
| 위험 신호 | 공격성·규칙 무시·우울 문항에 "그렇다"로 답했는지 | 0개 |
| 직무 적합도 | 성실·규칙·협동·정서·감정조절·민원·근무환경 7개 척도 | 60점 이상 |
| 응답 패턴 | 극단 응답, "보통" 비율, 1초 미만 응답, 미응답 | |

## 파일 구성

- `index.html`: 화면과 채점 로직 전부
- `questions.js`: 문항 은행. 한 줄이 한 쌍이에요. 문항을 고치려면 이 파일만 수정하면 됩니다.
- `README.md`: 이 설명서

## GitHub에 올리고 웹으로 여는 법

1. GitHub에 로그인 → 오른쪽 위 `+` → **New repository**
2. Repository name에 `Insung-test` 입력, **Public** 선택 → **Create repository**
3. 만들어진 화면에서 **uploading an existing file** 링크 클릭
   (또는 **Add file → Upload files**)
4. `index.html`, `questions.js`, `README.md` 세 파일을 끌어다 놓기 → 아래 **Commit changes**
5. 저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**
6. **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**
7. 1~2분 기다리면 위에 주소가 뜹니다: `https://아이디.github.io/Insung-test/`
   이 주소를 창규형한테 보내면 끝이에요.

## 기록 저장

푼 기록은 그 사람의 브라우저(localStorage)에만 저장됩니다.
다른 폰이나 다른 브라우저에서 열면 기록이 보이지 않아요.
